# Catálogo Musical

## Descripción
Aplicación web que permite buscar canciones y artistas utilizando la API de búsqueda de iTunes.

## Funcionalidades
- Buscar canciones por título o artista.
- Mostrar el título de la canción, el artista, el álbum y su portada.
- Visualizar los resultados en tarjetas adaptables a distintos tamaños de pantalla.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3
- API de búsqueda de iTunes

## Archivos del proyecto
- `index.html`: estructura de la página.
- `style.css`: estilos y presentación visual.
- `script.js`: consulta a la API y muestra los resultados.
